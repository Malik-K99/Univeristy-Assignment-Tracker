# University Assignment Tracker

A full-stack web application for managing university assignments and deadlines.

## Features

- Add assignments with a title, module and due date
- Mark assignments as complete or incomplete
- Delete assignments
- View total, pending and completed assignment statistics
- See the next upcoming deadline
- Validate form submissions and handle errors
- Store assignment data in an SQLite database

## Technologies

- **Frontend:** React, JavaScript, CSS
- **Backend:** Node.js, Express
- **Database:** SQLite
- **API:** REST

## Running the project locally

### 1. Start the backend

Open a terminal and run:

```bash
cd server
npm install
node server.js
```

The API runs at `http://localhost:3000`.

### 2. Start the frontend

Open a second terminal from the main project folder and run:

cd client
npm install
npm run dev

Open the local URL printed in the terminal, usually `http://localhost:5173`.
